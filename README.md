# 2D House Scene (Cena de Casa 2D)

A Python application that draws a house inside a specified window using the OpenGL library, then animates the scene.

## About

This project focuses on 2D computer graphics fundamentals: drawing shapes (a house) with OpenGL primitives inside a defined viewport/window, and animating the resulting scene. It's a hands-on exercise in translating geometric shapes into rendered 2D graphics.

## Concepts covered

- 2D drawing with OpenGL primitives
- Window/viewport setup
- Scene composition from basic shapes
- Animation of a 2D scene

## Tech stack

- **Language:** Python
- **Graphics library:** OpenGL

## Project structure

- `casa.py` — draws the house
- `animacao.py` — animates the scene

## Getting started

```bash
git clone https://github.com/Eduardo-Rais/cena-de-casa2D-python.git
cd cena-de-casa2D-python
python animacao.py
```

> Requirements: Python 3 and the OpenGL bindings used in the project (e.g. `pip install PyOpenGL PyOpenGL_accelerate`).
